### Divergence list (numbered, both directions)

Each: episode id, estate severity, shadow verdict, human label, notes.
SEV1/SEV2 divergences in a separate highlighted block — even when the
count is zero. *Especially* then.

### Calibration summary

Per confidence band (0.95–1.00, 0.90–0.94, 0.85–0.89, 0.70–0.84):
gate p(page) vs observed p(human paged), Wilson 95% bounds.
N<30 → **THIN — no claim**. >5pp miscalibration in any band with N≥30
**HOLDS** the stage gate.

### What is NOT in this report

No model metrics (accuracy/F1/ROC), no projected savings beyond the
labeled opportunity number, no remediation advice for the estate's
alerting. This report answers one question: *would Sentinel have
suppressed a real incident?*
